# Printer_4_Anycubic-Kobra_S1_Combo_Anycubic-Slicer

## Anycubic Kobra S1 Combo

The Anycubic Kobra S1 Combo is an enclosed CoreXY FDM printer for high-speed, single- or multi-color printing. The Combo includes an ACE Pro unit for four-color printing and filament drying.

![Anycubic Kobra S1 Combo](Pictures/pen%20holder_cavaliere_1.JPG)

### Technical overview

- Build volume: 250 x 250 x 250 mm
- Motion system: Enclosed CoreXY
- Print speed: 300 mm/s recommended; up to 600 mm/s
- Acceleration: 10,000 mm/s^2 recommended; up to 20,000 mm/s^2
- Hotend: 320 C maximum; standard 0.4 mm nozzle (0.25, 0.6, and 0.8 mm options supported)
- Heated bed: Up to 120 C, PEI spring-steel build plate
- ACE Pro: Four filament channels for four-color printing; active drying up to 55 C
- Supported materials: PLA, PETG, TPU (95A is not compatible with ACE Pro), ABS, and ASA

### Firmware and slicer

- Control firmware: Klipper in this setup; Anycubic lists Kobra OS as the stock firmware solution.
- Slicer: AnycubicSlicerNext.

Official specifications: [Anycubic Kobra S1 Combo](https://store.anycubic.com/products/kobra-s1-combo).
